## 6.2 地与层叠

- **4 层板**：L1 信号+器件，L2 完整地平面，L3 电源（分区铺 V5D/V3V3D/±5VA/V3V3A），L4 信号；
- **单地平面（AGND=DGND 电气同一）**，靠**物理分区**实现隔离：左上模拟输入 → 右上 ADC/DAC → 左下电源 → 右下数字/控制，模拟信号不穿越开关电源区；
- USB-C 屏蔽壳：**直连 GND 平面**（连接器两侧宽连接+多过孔——USB2 HS 信号完整性与 ESD 泄放要求低阻抗路径）；路径上**预留 0Ω 电阻位**：出厂 0Ω，若出现顽固 USB 地环可换 600Ω@100MHz 磁珠实验；
- XLR pin1：接 `CHASSIS` 网，**座体根部最短路径**（AES48 标准做法，屏蔽电流不流入音频地）；塑料机壳时 CHASSIS=金属面板/座体；
- 6.35 sleeve（备用输入/线路出/耳机）：接 GND——单端信号的回流脚，**不接 CHASSIS**；
- `CHASSIS` 网在 **USB 入口附近单点**接 GND（星形汇接点）；电位器/继电器金属外壳就近接 CHASSIS 或 GND，禁止悬空；
- 若组装后出现 USB 地环底噪（哼声随电脑负载变化）：① 先换屏蔽 0Ω 位为磁珠；② 输出平衡化（二期 OPA1632/DRV134）；③ 仍不行再上 I2S 数字隔离（川土微 CA-IS3720 系列，立创有货）——**PCB 上预留隔离器焊盘但不贴**。
- **塑料机壳（无金属面板）**：CHASSIS 网成员 = 连接器金属座体（Neutrik Combo 座自带金属体）+ 电位器外壳 + 内壁导电铜箔；pin1→座体→CHASSIS→单点 GND 方案照常。**机壳内壁贴导电铜箔（导电胶）接 GND**，或模拟区加铁皮屏蔽罩——塑料壳无法拉第笼，65dB 增益前置对 RF 敏感；将来换金属壳方案无缝。

## 6.3 上电/断电时序

```
上电：V5D → (V3V3D, **V1V8** 最早组) → (V0V9, ±5VA, V3V3A) → XU316 启动/ESP32 启动（**VDDIOB18 不得最后上电**）
     → ESP32 读 V3V3A PG=OK → 使能 XL6019(缓启) → 100ms → 闭 K1(若开幻象)
     → ES9822/ES9039 RST 释放 → I2C 初始化 → DAC 音量 -60dB → 500ms → 闭 K3 → ramp 默认音量
断电：检测 VBUS 掉电(ESP32) → 开 K3 → 音量 ramp -60dB → 开 K1 → 关 XL6019
     （常开继电器在电源跌落时天然断开，兜底防爆音）
```

## 6.5 打样验证顺序（每步全绿再下一步）

1. **电源**：不焊大芯片，测各轨电压/纹波；GM1205（V3V3A）输出用 6 位半表校 3.30V；
2. **XU316 最小系统**：焊 U10+Y1+U11+J1，xTAG 连接，`xflash` 烧 sw_usb_audio 最小固件 → Windows 出 ASIO 设备；
3. **数字链路**：焊 ES9822+ES9039（暂不焊模拟），跑 I2C 回读校验 + I2S 眼图 + 回环播放出声；
4. **模拟前端**：焊 PGA2500/运放/继电器，RMAA 自环测（线路出→线路入）与 -60dBFS 法测 ADC；
5. **联调**：混音矩阵/回环/限幅/UART 协议/屏幕 UI；**虚拟通道验证**：Windows 声音面板确认拆分出 3 个播放设备 + 3 个录音设备，三个 App 各指一个播放设备，OBS 采 "Stream Mix" 得到全混合流，DAW 采 "Mic" 得到干声；
6. **装机**：地环测试（换 3 台电脑、开关 LED 灯）、48V 热插拔 100 次、断连 100 次。
