## 3. 话筒、幻象与PGA2500

J4 pin1功能接CHASSIS；pin2/3各经输入RF网络，再接幻象6.81k馈电，之后47µF/≥63V双极性隔直，每腿10Ω初始脉冲限流后进入PGA VIN+/−。顺序不可反转。RF初值采用TI Fig7的1nF C0G/≥100V，回到连接器附近CHASSIS，这是对原220pF候选的工程修订，需作为新规格记录，不能混用低压50V件。

两只6.81k取≥1W、≥100V并按配对目标≤0.1%筛选。48V短路每只约0.338W，52V暂用包络约0.397W；这不含温度降额。每只47µF在48V储能约54.1mJ。输入钳位使用TI要求的≥10A浪涌功率肖特基级别，而不是BAV99替代；准确二极管及被注入的±5V轨吸收/钳位路径仍必须闭合。

PGA物理供电脚：18/19为VA+，15/20为VA−，14为VD−（由V5N_AFE经10Ω单独去耦）；6和28是地。负轨有极性旁路电容的正极在GND。浮动伺服电容：24↔23一只1µF、22↔21一只1µF。DCEN7接地使能；0dB8接地允许串口增益控制；ZCEN9经10k接V5P_AFE。VCOMIN25经0Ω接GND，以保留PGA输出摆幅。

SDI10、CS11、SCLK12由3.3V逻辑控制，初始≤1MHz，须避免AFE未供电时反灌。SDO13及OVR5是5V域，SDO返回MCU必须经5V容忍接收缓冲器；不能只按标称值设计一个无裕量的分压。GPO1–4未用标NC，OVR只引测试点。PGA的0dB不是静音；切幻象、切输入、改增益应先用真正的DSP/DAC及输出继电器静音。

来源：`PGA2500.pdf` p3–4、11–13。p4管脚图已重新渲染核对；输入钳位/耦合依据Fig7，输出交流耦合依据Fig8。

## 4. PGA到ADC：交流耦合与2.25V偏置驱动

不将PGA的0V输出直接送入ES9822，也不把PGA VCOMIN硬改2.25V。每个ADC通道增加一颗双运放OPA1612：话筒为U16，备用输入为U17。采用ESS p130反相驱动的拓扑，非反相端接由对应4.5V轨10k/10k分压、10µF+100nF滤波得到的2.25V共模。**不能用VREF9/22给外电路供电。**

每腿源信号→47µF/≥16V交流耦合→2k输入电阻→反相端；反馈电阻/并联C0G决定增益及低通。耦合电容优先双极性；若换为有极性，正极朝ADC驱动侧并核启停反向电压。驱动输出经36Ω送ADC脚，ADC差分脚之间100pF；不把这只100pF误接成每腿对地。36Ω/100pF采用ESS Fig29起点，增益电阻与耦合值是本版计算后的调整，不能称为完整照抄评估板。

| 驱动 | 反相输入信号 | 输出到ADC | Rin / Rf / Cf | 闭环信号增益（未计ADC负载） |
|---|---|---|---|---:|
| U16A | PGA_OUT_N | ADC_IN1_P | 2k / 1k / 680pF | −0.5 |
| U16B | PGA_OUT_P | ADC_IN1_N | 同上 | −0.5 |
| U17A | AUX_NEG_SELECTED | ADC_IN2_P | 2k / 2k / 330pF | −1 |
| U17B | AUX_BUF_P | ADC_IN2_N | 同上 | −1 |

输入正负交叉接到反相驱动，最终ADC差分保持与原输入同极性。话筒总差分增益0.5；备用输入为1。47µF与2k给出约1.69Hz高通；在20Hz约−0.031dB。反馈低通约234kHz/241kHz。这里仅是闭环简化计算，ADC表中430Ω及采样动态负载、36Ω源阻会改变实际增益/稳定性，不能将裸芯片3.2Vrms满幅直接当整条链路已保证值。

暂用检查点改为**PGA输出3.5Vrms差分→驱动约1.75Vrms差分**，对应TI p3实际列出的0dB/30dB、1kHz测试电平；它不是所有增益/频率下统一的满幅保证。Line输入2Vrms差分→驱动约2Vrms差分；Hi-Z输入1Vrms后生成±1Vrms两腿→约2Vrms差分。Mic驱动每腿约2.25±1.237V，Aux约2.25±1.414V。接近ADC3.2Vrms满幅时正侧约4.51V，必须重新核带载摆幅，不能假定OPA1612在最低+4.75V时仍有同样失真指标。

PGA的0dB输入另受每腿`VA−+1.5…VA+−2.0V`限制；VCOMIN=0时输入DC典型约−0.65V。以最弱±4.75V轨及这一典型DC值估算，对称差分正弦受负向2.60V峰值余量限制，约3.68Vrms差分。3.5Vrms时每腿AC峰值2.475V，最弱负向仅余约0.125V；这只是名义边界检查，不把典型−0.65V当保证，也不允许套用到非对称/有DC输入。高增益档输入预算应按3.5Vrms/10^(G/20)继续降低。

来源：`ES9822PRO_ESS.pdf` p61、129–130；`PGA2500.pdf` p13；`OPA1611_OPA1612.pdf` p3–5。ES9822模拟输入绝对负限−0.4V，过载/启停保护仍应验证；标准参考拓扑本身不能免除故障工况检查。

## 5. Line / Hi-Z与K2两刀的真实拓扑

U14A缓冲Tip，U14B缓冲Ring。两路连接器各经100Ω到输入，运放输入各有1MΩ到GND，形成明确DC回路。Ring连接器固定10.1k到地；Tip的10.1k由K2一刀接入或断开。**1MΩ是对地负载，不是串联输入电阻。**

U18A由两只10k组成反相器，输入取已缓冲的Tip，输出`AUX_HIZ_INV = −AUX_BUF_P`。U18B未用，但闭环跟随，+IN接GND，不能浮空。

| K2极 | 公共端 | LINE：断电NC | Hi-Z：吸合NO |
|---|---|---|---|
| A | AUX_TIP_TERM，通过10.1k到GND | J5_TIP | 不连接 |
| B | AUX_NEG_SELECTED，送U17A | AUX_BUF_N | AUX_HIZ_INV |

LINE模式Tip/Ring各约`10.1k || (1M+100Ω)=9.999kΩ`；Hi-Z模式Tip约1.0001MΩ。LINE差分来自Tip−Ring；Hi-Z由+Tip与−Tip构成差分对，两腿围绕相同共模驱动ADC，不使ADC的一腿悬空或直接接地。切换应静音；输入RF小电容可预留DNP，不能在1M串联之后机械加100pF形成音频衰减。

K2必须使用**非保持、单稳态、先断后接DPDT**，这里仅定义COM/NC/NO的电气功能，精确物理焊盘号须由实际继电器手册确认，不猜HFD4各后缀。

## 6. DAC电压模式与差分转单端

U21为一颗OPA1612，A/B分别左/右。每路实际四电阻：DAC_P经10k到+IN；DAC_N经10k到−IN；OUT经10k反馈到−IN；+IN经10k到GND。反馈10k并100pF，+IN对地10k也并相同100pF，匹配两支路。**没有把DAC正负脚相连，也没有只画一只模糊的“差放电阻”。**

ES9039每腿典型源阻390Ω，故理想对称条件：

`Gdiff = 10k/(10k+390) = 0.96246`

`Vdiff,open = (0.889×3.3)/sqrt(2) = 2.07444 Vrms`

`VSE,FS ≈ 1.99657 Vrms`

反馈极点约159.15kHz，20kHz约−0.068dB。10k网络需要比例匹配；DAC内阻±15%不等于两腿匹配保证，最坏不对称会产生共模泄漏和DC残留。高DNR电流模式的原厂测试指标不能直接移植到本电压模式输出。

每路SE输出经47.5Ω接K3.NO，K3.COM接线路输出Tip，K3.NC接GND；左右两刀。线路输出为不平衡单声道两个座，Ring/Sleeve按功能接GND。实际连接器焊盘号仍需机械手册。线路与耳机内容相同，但固定耳机衰减/电位器不会衰减线路支路。

来源：`ES9039Q2M_ESS.pdf` p54源阻/幅度/共模；`OPA1611_OPA1612.pdf` p3引脚；电压模式四电阻网络为本版工程计算，原厂p98–99的其他输出结构仅作为对比，未冒充它们的实测性能。

## 7. 耳机：TI参考G=2、39.2Ω及单独K4

TPA采用DWP 20脚，不混用14脚VQFN。左供电3/1、右供电18/20分别接V6P_RAW/V6N_RAW；两声道保持同电位。2为LOUT，19为ROUT；4/5为左+/−输入，17/16为右+/−输入；6–15均NC。PowerPAD接GND并焊接，原厂未给数值引脚号，表中记`EPAD`，**不擅自编为21**。

每路从DAC_SE经7.32k固定衰减电阻，再进10kA音量电位器；滑端100k到地作失效回路，经49.9Ω到TPA+IN。Rf=1k从**39.2Ω之前的放大器OUT**回−IN；Ri=1k由−IN到地，所以G=2。反馈中不并任何电容。

| 暂用32Ω/1Vrms检查量 | 数值 |
|---|---:|
| 每声道负载功率 | 31.25mW |
| 每声道负载电流RMS / peak | 31.25mA / 44.19mA |
| Ro=39.2Ω耗散 | 38.28mW，选≥0.5W并按温度降额 |
| 放大器端RMS / peak | 2.225Vrms / 3.147Vpeak |
| G=2所需输入 | 1.1125Vrms |

固定7.32k配10k电位器、100k滑端回路及TPA典型300k输入阻抗，最大音量名义衰减约0.5466，0dBFS时32Ω负载输出约**0.981Vrms**，接近保守1Vrms预算。电位器容差、源阻/输出摆幅及实际负载会改变结果；这不是经校准的硬件限幅器，也不保证其他耳机阻抗仍为同电平。

输出39.2Ω之后接K4.NO，K4.COM分别耳机Tip/Ring，K4.NC接GND；默认不通音频。K4采用与K3同样的非保持、先断后接要求。耳机独立静音，不能只依靠线路K3。硬件PG故障应强制释放K3/K4，软件仅在时钟锁定、电源稳定、静音初始化和DC检查后接通。完整DC故障检测目前未设计，投板前应补；不能把继电器默认断开写成对所有故障已经保护。

来源：`TPA6120A2.pdf` p3管脚/PowerPAD、p4最低供电、p5输入阻抗、p10 Fig14与10.2.1.2.1、p11–12稳定性、p16去耦。DWP管脚图已重新渲染核对。

## 8. 数量、网表检查与未关闭项

本方案音频IC共9颗：PGA×1、OPA1656×2（输入缓冲/Hi-Z反相）、OPA1612×3（两个ADC驱动加一个DAC差放）、ADC×1、DAC×1、TPA×1。JSON包含163条物理管脚记录（含三处EPAD记录）、144条通用支撑元件及继电器/接插件功能连接；这些不是生产BOM数量承诺。

主控/控制页仍需实现：PGA SDO的5V容忍接收；PGA/ESS未供电时的IO隔离；所有I2S/MCLK电平转换与传播时序；K1–K4驱动/硬件失效门控；ADC/DAC完整寄存器启动。电源页须承担本版增加的四路ADC驱动运放负载，不能仍使用旧“一个OPA1612”的功率预算。

图页可按该网络分模块绘制，但制造前还必须关闭：ADC实际驱动/采样负载稳定性；满幅摆幅和电压模式DC误差；幻象浪涌钳位及轨吸收；K1触点48V/电容冲击额定；K2–K4精确接点脚序与单稳态确认；耳机DC故障检测；去耦有效C/ESR/泄漏；布线后原生ERC/DRC和端到端网表核查。没有库存或品牌料号时仍可用明确通用规格绘制，不将这些电气未闭合项伪装成已经验证。

## 9. 与电源设计的交叉复核（2026-09-16）

| OPA1612共模与摆幅 | VCM范围V−+2…V+−2；2.25V输入共模在AFE最弱正轨约4.95V下距上界约0.70V。输出摆幅p6仅保证RL=2kΩ时距轨0.6V、RL=10kΩ时距轨0.2V；ADC430Ω/采样负载不属于这两个测试条件。1.75/2Vrms差分暂用点有几何电压余量，但线性与稳定性仍必须核实 |
| 幻象注入与LDO反流 | 47µF电容故障电荷经PGA功率肖特基进入AFE轨。TPS7A39不是轨能量吸收器，p35明确输出高于输入0.3V/负轨更负0.3V的反流风险。OUT→IN反向保护二极管可以保护LDO，但不会把PGA电源自动钳在±5.5V内；还须轨吸收/精密瞬态钳位和电容能量验收 |
| TPA失电输入 | TPA p4要求掉电时输入峰值<600mV。K4位于输出侧，且机械释放非瞬时，不能单独保证此输入条件。RAW电源异常应触发TPA输入硬钳低/隔离，先于或独立于AFE放电；未完成这条电路前不把断电安全标为已闭合 |
| 数字回灌 | PGA的CS上拉和SPI、ESS的I2C与时钟可能在音频域失电时仍为高。串100Ω只是阻尼，不是断电隔离；应通过真正Ioff能力的缓冲/总线开关/门控上拉及正确EN时序解决 |
| 继电器电源 | 旧5V线圈从最差3.8V的V5_SYS供电，不能未经精确型号pickup保证就批准。线圈不得直接加入已紧张的AFE轨；独立线圈支路、电流与关断回扫也必须进入USB预算。K1–K4可能3–4只同时吸合，若仅以旧30mA/5V作占位计算，耗电0.45–0.60W，已大于电源表其他裕量200mW；这不是已核线圈参数，但说明不能漏列。K1–K4要求非保持、先断后接，旧采购名称保留不等于已核该条件 |
