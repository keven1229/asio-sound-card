# 电源芯片数据手册逐份核验

核验期：2026-09-05～06。范围为本地 9 份电源 PDF；本机 `docs/datasheets` 实际共 **36 份 PDF**。本文新增，不修改历史草案、BOM 或他人的审阅报告。

**结论：分压公式大多能算出目标标称值，但电源树尚未满足最小输入、压差、热耗散、时序和替代兼容性要求。不能据此确认整机供电设计通过。** 最关键的是 XL6019 的 5V 最小输入与 USB 压降冲突、LM27762 从 5V 生成受载稳压 ±5V 的余量不足、AP7361C 前级 3.6V 的最差余量，以及 SY6280 反向阻断的关断条件。

## 核验口径与资料版本

- 本文 `p.N` 一律是从 PDF 第一页起算的**物理页码**，不引用搜索摘要中的页码。表格经过文本提取；AP7361C、GM1205、LT3045、SY8089、TPS7A20、XL6019 的关键数值列和 GM/LT 封装图另做渲染复核。
- `typ` 是所列条件下的典型值；`min/max` 也只有在表头条件、温度和脚注成立时才适用。保护阈值不是可持续工作电流；绝对最大值不是建议电压。
- 公式计算是静态预算，不是测量。未指定 MLCC 具体料号时，不能宣称某电容偏置后“必剩 1.3µF”或“已超过最低有效容量”。必须用实际料号的直流偏置、容差、温度和老化曲线。
- 对照对象：`docs/schematic/01-power.md` §1.2–1.7、`docs/hardware-devices-design.md` §2.2 / §3.1–3.7、`docs/BOM.csv` U1–U7 及 U2B。它们是历史设计输入，不作为手册参数的证据。

## 跨器件结论与待关闭项

1. **重画供电能力边界，而不是只补阻容。** XL6019最小输入、LM27762余量、AP7361C前级最差值都是拓扑/预算问题。12V PD路径必须先经过能承受12V的前级，不能直送SY8089/SY6280/低压LDO。
2. **禁止按typ限流值承诺最大负载。** SY6280的0.75–1.25A、LT3045的450–550mA已明确有范围；GM限流标度只有typ，还需厂商保证数据。
3. **替代清单至少细化到封装/脚功能/参数条件。** GM→LT需要同时改ILIM、检查PG/EN和20mΩ ESR；TPS→SGM要检查BP、容量上界、热、1.8V精度、EN和放电行为；SY8089不同A后缀不是同一器件。
4. **补料号级外围证据。** 每只电容写制造商料号与有效容量下限；电感写L容差、Isat温度条件、Irms/DCR；输入热插拔与USB浪涌、反向供电/掉电储能一起核验。二极管/TVS等未在本9份中提供手册，不能据这9份给它们签核。
5. **保留原厂文件不一致并推动确认。** GM迟滞20/60mV、压差脚注100/300mA、首页/电气PSRR口径不能静默抹平；LT本地B版PG公式要切换到D版；SGM本地B.1缺新版电容边界；SY本地初版数据与新版差异需明确。

本轮验证了参数来源和设计冲突，没有制作新的供电原理图、修改BOM、通电测量或验证热/纹波。9/9文件“已核验”表示覆盖完成，不表示9个方案均已通过。
