## 核验结论：XU316的核心确实是0.9V

**本项目XU316-1024-QF60A-C24，VDD核心与PLL_AVDD均为0.900V，工作范围0.855～0.945V。** 电压表见本地PDF物理第31页（印刷第30页）§14.2 Figure31；已放大原表核对MIN/TYP/MAX列，并与XMOS官网2023版交叉核对。

0.9V分压计算：`0.6 × (1 + 100k/200k) = 0.900V`，标称算式正确。但在VFB0.588～0.612V及两只1%电阻下，静态端点约0.8762～0.9242V，还未包括负载/温度/纹波/动态压降。**“算得0.9V”与“在所有工况满足0.855～0.945V”是两个验收项目。**

## 对原设计最重要的勘误

1. **核心和底部焊盘**：XU316底部61–64是VDD，65才是GND；无独立OTP_VCC外脚。删除“挂起态0.85V”和虚构电压选择strap的无依据描述。
2. **逻辑电平**：XU316输出VOH保证值为1.35V（指定2mA条件），不是所有负载下恰等于1.8V。ESP32与当前两ESS的输入门槛都不能由其保证驱动；PGA反向SDO也需降电平。CH343P则可用独立VIO设置1.8V，须按真实脚位/指标设计。
3. **DAC时钟与封装**：ES9039Q2M是32-QFN，MCLK≤50MHz；192k异步需MCLK≥约24.96MHz，24.576MHz不是合规的异步替换。ES9038Q2M备选实际为30-QFN 5×3mm，也不是旧稿的QFN-40。
4. **ADC供电/共模/启动**：补4.5V轨；输入共模约AVCC/2=2.25V；先用同步I2C窗口启用时钟，再访问普通控制地址。不能只写“差分直连、上电读ID”。
5. **内部核心节点必须逐型号处理**：ES9018K2M明确有外供1.3V条件；9038/9039/9822当前PDF没有建立同样外供模式。只否定已超过abs的旧1.8/3.3V接法，不把它泛化成所有芯片DVDD一律不能外供。
6. **电源误差与兼容替代**：AP7361C 3.6→3.3V最差余量不足；SY6280反向阻断有shutdown条件，不能直接证明双输入OR-ing；GM1205/LT3045同脚序不等于ILIM、PG、ESR和保护行为完全兼容。
7. **模拟及外围**：PGA0dB不是静音；THAT5171/5173伺服比例不同；EC11最小接点电流与旧10k/内部上拉不匹配；TVS名称中的5V不是5V钳位，CC的Rd也不是ESD保护器。

核心、ADC/DAC和电源页已回写关键参数；未闭合的输入/输出级、电源路线与BOM选型继续标为待设计。旧器件汇编和2026-09-05审阅中的行号是当时快照，后续应以本核验表的原厂版本/页码/章节定位。

## 原文自身存在的疑点

- **GM1205**：原厂PDF与本地哈希相同，但PGFB迟滞、压差表/脚注、PSRR宣传与参数表口径不一致。
- **LT3045 / SGM2036 / SY6280**：本地不是本轮取得的较新原厂版本；修订差异已列在电源报告。不能把旧版公式与新版条件拼成一组保证值。
- **THAT5173**：p8 SPI脚号表与p2引脚表不一致；**THAT626x**的单电源应用与绝对最大表有冲突。
- **NE5532**：同文件的电源极限、GBW、压摆率文字/单位存在差异；相关值未强行认证。
- **ES7210 / ES9822**：手册不同章节的速率/时钟描述有差异；已列明确配置与需保守处理的范围。

这些项需要更正版手册或厂商明确答复，不能选一个较好看的值当作已确认参数。
