# 硬件设计流程：画图顺序与图页划分

> **2026-09-05：图页划分可作为工作组织参考，具体接法/数值仍未冻结。** 正式画图前先处理[整体设计整理](design-review-2026-09-05.md)中的电源、电平、ESS封装/时钟冲突；AI工具状态见[环境说明](easyeda-ai-environment.md)。

> 配套文档：原理图级设计 [schematic/README.md](schematic/README.md)（命名规范/ADR）、[06-system.md](schematic/06-system.md)（打样验证顺序）。本文件只管"**按什么顺序画、图页怎么分、每页画到哪算完**"。

## 0. 工具选择

- **立创EDA 专业版（推荐）**：BOM 里全部 C 编号可直接检索导入（符号+封装+价格一起带出），画完一键转嘉立创下单 + SMT；库最全；
- KiCad 8（备选）：开源可控，但 XU316/ES9822/ES9039/PGA2500/TPA6120A2/LM27762 都要自建 symbol，工作量大一截；
- **本项目直接上立创EDA 专业版**，C 编号就是它的零件库编号。

## 0.5 封装选用规范（全板默认 0603）

- 默认被动件 **0603**（手焊/返修友好；无必须 0402 的密度点；嘉立创 SMT 两者同价）。个别 QFN 引脚间塞不下时局部 0402。
- 电阻功率参考：0603=0.1W、0805=0.125W、1206=0.25W、1210=0.5W。
- **例外表（画图必守）**：

| 位置 | 封装/类型要求 | 原因 |
|---|---|---|
| 幻象馈电 6.81k×2 | **1206/1210，0.25W+，0.1% 薄膜** | 正常功耗≈0.33W/只，0603 会过热漂移 |
| 信号路径电容（220p/470p/2.2n/330p） | 0603 **C0G** | 音频路径禁 X7R（压电/偏置失真） |
| 精密/反馈电阻（RSET/分压/差放 2.2k/TPA6120 1k） | 0603 **薄膜 1%** | 精度与噪声 |
| 1µF 及以上 MLCC | **0805+**（TPA6120 贴身 1µF 例外） | 0603 大容量偏置衰减严重 |
| 音频耦合 47µF/63V | **通孔电解双极性** | 无 SMD 规格；**固态/聚合物不可用于信号路径**，发烧升级换薄膜 |
| 电感 2.2µH/47µH | 一体成型贴片（SWPA/CD75） | 功率件 |
| 其余去耦/普通电阻 | 0603 X7R / 0603 厚膜 | 默认 |

## 1. 五条总原则

1. **先建库、后画图**：自建 symbol 的阶段就把 datasheet 引脚核对完——"核对红线"必须前置，不能画到一半才发现引脚错；
2. **自下而上、先数字后模拟**：电源 → 主控 → 数字接口 → 模拟前端 → 输出 → 控制。理由：电源网名是所有页面的公共接口；XU316 的引脚复用冲突必须最先解决；模拟页最后连，避免反复改网名；
3. **一页一功能，页间用网络名 + 端口符号**连接，禁止跨页飞线；
4. 位号前缀与网络命名严格照 [README §3](schematic/README.md)（`R/C/U/J/TP`、`V3V3A/ADC_BCLK/CTRL_TX`…），后面 ERC/BOM/SMT 全靠它；
5. **每画完一页立刻勾一遍 §5 核对清单**，不要攒到最后一起返工。

## 2. 画图顺序（含理由与完成标志）

| 步骤 | 内容 | 为什么这个顺序 | 完成标志 |
|---|---|---|---|
| 0 | 建库：自建 12 个 symbol（见 §5） | 引脚核对前置 | 每个 symbol 引脚名与 datasheet 一致 |
| 1 | **电源页（S2）** | 全部页面的网名接口；上电顺序先定 | 8 条电源轨 + 时序注释齐全 |
| 2 | **XU316 主控页（S3）** | 引脚最多、复用冲突最先暴露；决定 PCB 骨架 | I2S/UART/xSYS/Flash 引脚分配定稿 |
| 3 | 话筒前端+幻象（S4） | 模拟指标核心，尽早冻结 | 幻象信号顺序图核对无误 |
| 4 | 备用输入（S5） | ch2 独立，可与 S4 并行 | 继电器两刀分配正确 |
| 5 | ES9822（S6） | 接 S3 的 I2S/S4-5 的模拟 | I2C 地址与 ES9039 错开确认 |
| 6 | ES9039+输出（S7/S8） | 接 S3 I2S、S2 电源 | 防爆音状态机标注在页注释 |
| 7 | ESP32+面板（S9/S10） | 最独立，放最后不影响全局 | UART/I2C/继电器网名与协议表一致 |
| 8 | 接插件/TP 汇总（S11） | 收尾 | 与 06-system §6.4 测试点表一致 |
| 9 | ERC/DRC 全检 + 出 BOM | 出图前 | 全绿 + BOM C 编号 diff 为 0 |
| 10 | 下单打样 → 转 [06-system §6.5](schematic/06-system.md) 验证 | | |

> 业余节奏参考：每页 0.5~2 天（含核对），全机 2~3 周；**S2/S3 最慢属正常**，不要急。

### 3.2 精简版（6 页，先画骨架再拆）

S1 电源 | S2 主控 | S3 模拟前端（S4+S5+S6 合并） | S4 DAC+输出（S7+S8 合并） | S5 控制（S9+S10 合并） | S6 汇总。
**建议：用精简版把骨架和网名打通，再拆成 11 页标准版**——拆页只动纸张不动物理连接，风险最低。

## 4. 每页要点清单（画到这些才算完）

**S2 电源**
- [ ] SY8089/SY6280/XL6019 反馈电阻计算值标注在图上（0.9V/3.6V/48.2V）；
- [ ] GM1205 的 RSET=33k/CSET=4.7µF 齐、ILIM 电阻按 GM1205 手册计算（勿照抄 LT3045 的 600Ω）；
- [ ] 每个下游负载的磁珠+去耦画全；
- [ ] 页注释写"上电/断电时序"（抄 06 §6.3）。

**S3 主控**
- [ ] 对照 XK-AUDIO-316-MC 官方原理图逐脚核对电源/晶振/Flash/USB（直接照抄）；
- [ ] I2S×2、UART、xSYS 引脚分配定稿并回填到 README 2.2 表；
- [ ] 所有剩余 IO 引出测试排针；
- [ ] 22Ω 串阻源端放齐。

**S4 话筒**
- [ ] 信号顺序：EMI→6.81k→耦合电容→PGA2500，顺序标注在图上防改错；
- [ ] PGA2500 VD+ 接 V5D（5V）、VA± 接 ±5VA，四组电源去耦齐；
- [ ] 47µF/63V 双极性、100k 泄放、220pF RF 旁路齐。

**S6/S7**
- [ ] ES9822 DVDD 电压**当场查 datasheet** 定 1.8V 还是 3.3V（决定 U4 贴不贴）；
- [ ] ES9822 与 ES9039 的 I2C 地址错开（ADDR 引脚标注）；
- [ ] ES9039 供电脚名按 datasheet（AVCC_L/R/VCCA/DVDD），别照抄 ES9038；
- [ ] 100M 晶振电源必须画在 V3V3A 上。

**S8**
- [ ] 差转单四电阻 2.2k + Cf 330pF 标注；
- [ ] TPA6120A2 三级去耦（10µ+1µ+0.1µ）画在引脚边并加注"毫米级贴身"；
- [ ] 输出 10Ω、K3 常开、防爆音状态机写页注释。

**S9/S10**
- [ ] UART 921600、I2C 2.2k 上拉、PGA2500 四位段（CS/SCLK/SDI/SDO）；
- [ ] 继电器线圈接 V5D、2N7002 栅极 1k+100k、SS14 续流；
- [ ] 屏幕 FPC 与旋钮位置先对 3D 外壳再锁坐标。

## 6. 出图前检查

1. **ERC**：未连接引脚全清（无意的 NC 要显式打 ×）；电源引脚加 PWR_FLAG；
2. **单地平面检查**：AGND 与 GND 确认电气同一（本项目不分地）；屏蔽/机壳用独立 `CHASSIS` 网络——XLR pin1→CHASSIS（AES48）、USB-C 屏蔽壳直连 GND（预留 0Ω 位）、CHASSIS 在 USB 入口单点接 GND；
3. **网络命名 diff**：把网表导出的电源/I2S/UART 网名与 README §3 表比对；
4. **BOM diff**：生成 BOM 后与 [BOM.csv](../BOM.csv) 的 C 编号逐一比对，缺料（HFD4/NZ2520SD/Neutrik）提前在淘宝下单；
5. **DRC + 下单**：立创EDA 直接转嘉立创，4 层板参数照 06 §6.2。
