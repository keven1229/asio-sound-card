## 1. 统一默认规则

- **封装尺寸均先说英制**：0603=1.6×0.8mm，0805=2.0×1.25mm，1206=3.2×1.6mm，1210=3.2×2.5mm，2512=6.3×3.2mm。磁件的4×4mm、外壳高度和电解脚距要直接按毫米指定，不能与这套代码混用。
- 普通小电阻默认0603、1%、≥0.1W、工作电压≥50V、温漂≤100ppm/°C。电源反馈与精密模拟电阻优选薄膜0.1%、≤25ppm/°C；这些是本项目的工程筛选建议，不是所有IC手册强制要求。
- 普通去耦100nF默认X7R/25V/±10%/0603；1～4.7µF从0805起选，10～22µF从1206/1210起选。**封装和额定耐压不能证明有效容量**，不足时扩大封装/换料号或按环路允许并联。
- 信号滤波的小电容优选C0G/NP0；普通电源去耦可以X7R。并非“音频电路里的所有电容都必须C0G”。芯片特别指定的钽、伺服和参考节点单列。
- 普通阻容可在原理图阶段使用上述通用规格。大功率电阻、电感、电解、共模扼流圈和接插件的外形/脚距必须在PCB布局前落实。

CSV的状态含义：**可先落图**=已有明确用途与名义值，仍需核料号；**条件候选**=可在对应草稿拓扑中标注候选，须验算；**待计算**=数值或电源/模拟拓扑未定，不能当作采购批准。厂家料号可以后补，电气功能不能留到制造时再决定。

## 5. 三个值得先算清楚的小例子

**幻象馈电电阻**：48V对地持续短路时，每支`P=48²/6810≈0.338W`。本表暂以52V包络算约0.397W，若计1%电阻下限则约0.401W（52V不是已冻结的V48容差）。**0.5W件只有在实际板温降额后仍覆盖此功耗并留有余量时才可用，1W更宽裕**；不直接批准普通0.25W。封装大小不等于额定功率。两支分别计算，不把总功耗平均到两只。

### R23采购可实现性修订

不再同时要求“薄膜＋单颗0.1%＋1W＋25ppm”作为硬筛选。原厂[THAT DN140 p1](https://thatcorp.com/datashts/dn140.pdf)对其幻象馈电网络建议1%或更好，并因厚膜可能有额外电流噪声而优先薄膜；[TI PGA2500EVMV2 BOM p16](https://www.ti.com/lit/ug/sbou257/sbou257.pdf)使用6.81k、0.1%、0.4W薄膜。TI评估板的额定与使用条件不能直接代替本机52V短路/温度设计。

- **优先采购路线**：6.81kΩ、1%或更好、低噪声薄膜/金属膜，0.5～1W，额定工作电压≥100V。可以买1%件筛配，或选0.1%件后复测；两支0.1%件的最坏相对差也可能达到约0.2%。
- **更容易采购的打样路线**：6.81kΩ、1%、厚膜、1W级，其他耐压/温度条件满足后先列为候选。筛配解决阻值差，**不解决厚膜额外电流噪声、温漂和长期漂移**；须在真实幻象偏置、电流、增益和带宽下验证噪声后才作性能定稿，不宣称与薄膜等效。
- **配对方法**：暂以`abs(Ra-Rb)/((Ra+Rb)/2) <= 0.1%`为本项目目标，6.81k附近约要求差≤6.8Ω。先选每支接近6.81k、符合绝对阻值目标的件，再在同温度、相同接触和量程下比较。仪表分辨率宜1Ω或更细，重复性与相对测量不确定度应明显小于6.8Ω；仅显示相同“6.81k”不能证明配对。室温筛选后仍需检查工作温度和自热下匹配。
- **温漂**：≤25ppm是原先的优选目标，不是PGA2500的硬门槛。现在优先≤50ppm，≤100ppm可评估；两颗各自的TCR上限或“同批”均不能保证成对跟踪。

这一修订允许更宽的采购候选，不自动降低噪声/匹配验收目标，也不影响其他电阻规格。修订行已另存[passives-r23-revision.csv](passives-r23-revision.csv)，原CSV当前不可写，未覆盖；厂家/MPN/C编号继续由实际选择回填。

**耳机输出10Ω电阻**：50/100/200mA RMS对应25/100/400mW。若再按不超过温度降额后额定功率的50%作为本项目设计目标，200mA需要至少0.8W有效额定能力，因此会选1W级或更高；最终仍取决于耳机负载、输出范围和温度。

**EC11接点**：2.7k/1%在3.0～3.6V下约1.10～1.35mA；4.7k/1%约0.632～0.774mA，分别满足本地型号旋转1mA、按键500µA要求。推荐候选连接为：

```text
3.3V ── Rpull(旋转2.7k / 按键4.7k) ──┬── Rseries 1k ── MCU输入
                                      │                  │
                                    接点                100nF
                                      │                  │
                                     GND                GND
```

上拉在接点侧，1k只在MCU支路，避免降低湿润电流，并限制电容向接点放电。100nF是候选，下降沿约100µs，释放上升沿还包含上拉电阻；两者都不能代替完整的软件机械消抖。GPIO漏电/阈值、接点实际电阻和高速旋转也要验证。

## 6. 后续怎么落原理图和BOM

1. **原理图先用通用规格**。填写`Spec_ID`、数值、容差、额定耐压/功率、介质、封装目标、装配选项和设计状态；用真实存在的通用符号/器件或本地库，不虚构UUID，也不借用错误厂家料号冒充已选。
2. **可空着的是厂家、MPN、LCSC和数量**。位号/数量由实际绘制后生成；同一Spec_ID可对应多个位号。带不同耐压/功率/介质/匹配要求的同数值元件，必须是不同Spec_ID，不能按Value一列合并。
3. **PCB前落实物理封装**。普通0603可先约定占位；电解、电感、钽壳号、功率电阻、晶体、接插件必须确认焊盘/脚距/高度/极性和机械位置再布局。品牌可继续比较，但不能指望换料后焊盘一定兼容。
4. **你选好料后回填CSV的MPN/C编号**，再核规格、原厂曲线、引脚/封装，赋予`Part_Status=已核料号`，回填真实原理图并导出BOM、网表核对。CSV不是生产导入模板，最终以EDA实际位号清单为准。
5. **尚未计算的电路先保留TBD/DNP**。例如GM限流、48V功率磁件、ADC/DAC滤波、模拟电源反馈；可以显示在草稿/待办页，不能当作已批准元件发板。

保护器件和接插件不宜只用通用阻容规则选：2N7002要核3.3V栅压下的RDS(on)，TVS要核实际钳位与脉冲，PTC要核板温下Ihold，继电器/音频座/USB座必须有精确脚序和尺寸。这些继续放在现有[BOM候选表](BOM.csv)，本轮没有替你选定具体采购型号。
